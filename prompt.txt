### 📋 CSV 轉 Excel 桌面工具開發 Prompt

> **角色與開發風格**
> 請幫我用 Python 開發一支「CSV 批次轉 Excel」的本機桌面小工具。程式碼架構請採用**純函式寫法**，**不要使用類別（`class`）**，也避免太冷門或複雜的進階語法，以**結構直觀、好閱讀、好維護**為最高原則。
> **使用套件**
> * 介面：`tkinter`（搭配 `filedialog`、`messagebox`）
> * 資料處理與寫入：`pandas`、`openpyxl`
> 
> 
> **核心功能需求**
> 1. **目錄選擇與檔案清單**：
> * 點擊按鈕可選擇本機資料夾，自動掃描並列出該目錄下的所有 `.csv` 檔案。
> * 清單需支援**捲動軸**，每筆檔案前附帶可勾選的核取方塊（Checkbutton），並提供「全選 / 全不選」按鈕。
> 
> 
> 2. **輸出模式（單選按鈕）**：
> * **合併模式（預設）**：將勾選的所有 CSV 合併寫入**同一個 `.xlsx` 檔案**（檔名加上時間戳記避免覆蓋），每個 CSV 各自成為一個獨立分頁（Sheet）。需自動處理 Excel 分頁名稱限制（最長 31 字元、過濾 `\ / ? * : [ ]` 非法字元、自動編號避免重複名稱）。
> * **獨立模式**：將勾選的 CSV 各自轉成同名的獨立 `.xlsx` 檔案。
> 
> 
> 3. **輸出路徑規範**：
> * 自動偵測目前執行檔（`.py` 腳本或打包後的 `.exe`）所在目錄，並在該目錄下自動建立 `output` 資料夾統一存放轉出的 Excel 檔案。
> 
> 
> 4. **資料防呆與排版優化**：
> * **防亂碼**：自動依序嘗試 `utf-8-sig`、`utf-8`、`cp950` 編碼讀取 CSV。
> * **保留前導零**：讀取 CSV 時強制將所有欄位視為純文字（`dtype=str`），避免店號、郵遞區號或電話開頭的 `0` 被吃掉。
> * **自動調整欄寬**：寫入 Excel 後走訪各欄位計算內容最大寬度（中文字元寬度算 `2`、英數符號算 `1`），加上適當留白並設定最大寬度上限，讓表格開啟即整齊好讀。
>
